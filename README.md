# Gemini Guarder · Antigravity 2.32.2

使用 Antigravity 已启用的本机回环调试端口，在主页面的隔离 JavaScript 环境中挂载 Shadow DOM 面板与翻译观察器。

## 安装、更新和还原

需要 Windows 和 Node.js 22 或以上。Gemini 挂载使用 Google Chrome，视频使用 PATH 中的 ffmpeg.exe 和 ffprobe.exe，也可分别通过 GUARDER_FFMPEG 与 GUARDER_FFPROBE 指定。解压后在项目目录打开 PowerShell。

- 安装或更新运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`。安装会将本地插件登记到 Antigravity 的全局插件目录，桌面界面由独立的 Windows 伴随进程挂载。应用正在运行时直接挂载，未运行时正常启动。守护进程通过当前用户的登录任务启动。若刚启动的官方 Antigravity 缺少回环调试端口，守护进程会正常退出并重开一次，之后恢复挂载。新版若调整主页面入口或控件结构，需要重新验证。
- 一键还原运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1`。脚本停止后台进程、撤销翻译并移除面板。应用包保持原样，无需覆盖应用文件。
- 只备份可追加 `-NoLaunch`。备份位于 `%LOCALAPPDATA%\Guarder-Antigravity\backups\<ASAR SHA-256>`，包含 `app.asar` 和 `app.asar.unpacked`，首次备份会逐文件核对哈希。卸载保留备份与用户数据。
- 挂载状态和日志位于 `%LOCALAPPDATA%\Guarder-Antigravity`。如果脚本在等待，请先进入 Antigravity 主界面。

## 使用

- 点击右下角 **Gemini Guarder**，或按 **Alt+Shift+G**。面板可选择简中、繁中、英语、日语和韩语。默认简中并开启「同步翻译 Antigravity 主界面」。关闭同步或选择英语会还原已改写控件的英文。
- 主题页的顶栏颜色支持跟随系统背景、智能识别和自定义选择。默认智能识别，按壁纸实际裁切后的顶部八个区段生成渐变，视频由帧回调驱动，取样间隔下限约 66 毫秒。没有可取样的壁纸时显示宿主顶栏。主题页的字体和输入框背景各有一个宿主颜色复选框。勾选时使用宿主实时颜色，取消勾选时使用旁边的自定义色。自定义输入框颜色统一作用于输入框、宿主菜单、提示、对话框、命令面板及设置弹窗表面，并为文字选择对比色。主题页可单独调整左侧栏背景不透明度，范围为 0%–100%，初始值 72%。关闭壁纸会恢复原侧栏及聊天底部渐变。壁纸库共用可读取的旧素材目录，壁纸选择独立保存。支持按标题或标签搜索、按类别筛选、按名称或大小排序、收藏和预览。壁纸库预载固定尺寸的封面，悬停时在原位置请求播放预览。仅有场景工程且无媒体的条目标记为无预览。支持的格式从本机媒体服务播放，其余优先使用已缓存的短片，必要时转码。应用后使用完整视频。主题页的播放状态预览独立显示视频原画，背板不透明度只影响宿主对话区。缩放范围为 0%–100%，35% 时使用原比例的铺满布局。低于 35% 会显示背景边缘，更高则放大裁切。支持拖入或选择本地文件，分块导入上限为 1 GiB。
- 划词后按 **Alt+Shift+V** 保存，或单击面板里的保存按钮。生词本沿用 `Documents\GPT Salad Vocabulary`，支持收藏、编辑笔记和归档。只有显式保存或编辑才写入共享目录。Notion、Obsidian 和 OneNote 地址可编辑和打开。「同步词条」复制对应格式，由用户粘贴。此电脑已将旧面板的预填地址放入本地配置，源码包不包含私人地址。
- Gemini 页打开后自动将独立 Chrome 应用窗口挂载到面板，切换分页会隐藏已归位的窗口。默认槽位禁用最小化。拖离槽位后最小化，Gemini 会回到默认位置与尺寸。首次使用这个专用 Chrome 配置时可能需要登录。「翻译选中文本」将提示词写到剪贴板，由用户粘贴提交。
- 旧配置和壁纸数据从 `GPTDADDY_DATA_ROOT` 或 `%LOCALAPPDATA%\GPTDaddy` 读取。新语言和壁纸选择写入 `%LOCALAPPDATA%\Guarder-Antigravity\settings.json`。

## 覆盖范围和验证

- 词典包含 326 条五语精确映射。已验证常规、应用程序、外观、快捷键、通知、模型与用量、浏览器和对话设置的标题与常用控件。也处理已确认的快捷键无障碍标签、设置下拉项、技能与插件区标题。Electron 原生菜单、嵌入网页、第三方插件内容、未知提示和部分动态文案仍可能显示英文。
- 前端主脚本由本地 HTTPS 服务提供，Electron 系统菜单由 ASAR 内的 `dist/menu.js` 创建。DOM 观察器监听文本及标题、提示等属性，并按祖先节点排除代码、样式、脚本、聊天输入、Monaco、终端和内嵌浏览器。安装会验证词典的半角标点序列，遇到对应的全角标点即停止。
- `node .\run.mjs --verify` 查看挂载状态。`node .\verify-live.mjs` 在当前页面中创建临时隐藏测试控件，验证五语切换、属性和动态节点、受保护内容及恢复，随后移除测试控件并返回简中同步状态。
- 本机验证了 Gemini 最小化归位、完整视频播放、35% 全窗口覆盖、27 MiB 分块导入，以及卸载还原和重挂载后的设置恢复。共享生词本当时为空，外部词库同步和 Windows 整机重启未实测。
