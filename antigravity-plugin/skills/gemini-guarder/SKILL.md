---
name: gemini-guarder
description: Help the user open Gemini Guarder and find its wallpaper, Gemini, vocabulary, and language controls in Antigravity.
---

Open the Gemini Guarder desktop panel with Alt+Shift+G. The Theme tab manages wallpaper, conversation backdrop, and sidebar opacity. The Settings tab changes the panel language. The Gemini tab displays the docked Gemini window. Select text in Antigravity to use Guarder's selection menu.

The Windows companion launched by the Gemini Guarder installer supplies these desktop controls. If the shortcut has no effect, verify that the companion is running before claiming any settings have changed.
